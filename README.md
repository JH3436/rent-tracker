# 房租追蹤器

這是一個可以放到手機主畫面的靜態 PWA 小工具。資料會儲存在目前裝置的瀏覽器中。

## 手機使用方式

把整個資料夾部署到支援 HTTPS 的靜態網站，例如 GitHub Pages、Netlify 或 Vercel。

部署後在手機瀏覽器開啟網址：

- iPhone Safari：分享 > 加入主畫面
- Android Chrome：右上選單 > 新增至主畫面 / 安裝應用程式

加入主畫面後可以像一般 app 一樣開啟。第一次成功載入後，基本檔案會被快取，之後可離線使用。

## 注意

電腦和手機的資料不會自動同步。若之後需要同步，可以再加上雲端資料庫或匯出 / 匯入功能。
